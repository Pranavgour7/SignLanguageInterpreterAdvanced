System Pipeline

How the System Works

A four-stage real-time computer vision and machine learning pipeline operating purely on your device.

Stage 01

42-Point Landmark Tracking

Captures all 21 hand joints (x, y) in real time with MediaPipe Hands WASM, tracking every knuckle, joint, and fingertip.

Stage 02

Wrist-Relative Normalization

Translates landmarks relative to the wrist (x₀, y₀) and scales by bounding radius. Signs are recognized accurately anywhere on screen.

Stage 03

100-Tree Parallel Forest

Evaluates 100 decision trees in pure JavaScript in <0.3ms without external matrix math or server roundtrips.

Stage 04

Dynamic Flow Debouncing

Detects rapid sign transitions in <200ms when confidence is high, enabling fluid real-world continuous signing.
